# Lost for Words — Family Law Case Law Semantic Search (BETA)

A semantic search prototype for EWFC decisions,
built as part of a collaborative PhD project between King's College London and
The National Archives, exploring how to bridge the vocabulary gap between
everyday language and legal language when searching case law.

Judgments are indexed at the paragraph level using sentence-transformer
embeddings, and each case is tagged with plain-English legal concepts drawn
from Citizens Advice, so that results can be understood by non-lawyers.

> **This is the BETA prototype**, the second iteration in the project, intended
> for deployment. It builds on the earlier
> ALPHA prototype (deployed at **(https://research.caselaw.nationalarchives.gov.uk)**), and found on case-law-semantic-alpha repo. 

> **Status:** research prototype. Currently uses Pinecone for vector storage;
> migration to AWS S3 Vectors is in progress (see *Deployment notes* below).

---

## How it works

The pipeline has three stages, exposed as command-line subcommands on a single
script (`beta_app.py`):

1. **`embed`** — Parse Find Case Law XML judgments (Akoma Ntoso format),
   extract paragraphs and metadata, generate embeddings, and tag each case
   with Citizens Advice legal concepts. Output is saved to a local pickle file.
2. **`upsert`** — Upload the saved vectors to the vector database.
3. **`search`** — Launch a Streamlit web interface for semantic search.

```bash
python beta_app.py embed     # parse + embed + tag
python beta_app.py upsert    # upload vectors to the index
streamlit run beta_app.py    # launch the search UI
```

## Requirements

- Python 3.13
- See `requirements.txt` for Python dependencies.
- A vector index (currently Pinecone; **384 dimensions, cosine similarity**).
- Citizens Advice concept definitions with embeddings (`ca_terms_all.pkl`),
  generated by `create_ca_embeddings.py` from `ca_terms_all.csv`.

Currently using Pinecone vector store with personal API key - needs changing to fit AWS requirements.

## Repository contents

| File | Description |
|---|---|
| `beta_app.py` | Main pipeline: embed / upsert / search |
| `create_ca_embeddings.py` | Builds CA concept embeddings from the CSV |
| `ca_terms_all.csv` | Curated Citizens Advice concepts (title, definition, source, area) |
| `requirements.txt` | Python dependencies |
| `.gitignore` | Excludes vectors, corpora, and secrets |

**Not included in the repo** (too large / regenerable / not for version control):

- The XML judgment corpus (`caselaw_fam_xml/`)
- Embedded vector files (`*.pkl`) — these are large (~1GB+) and regenerable
- Any credentials or `.env` files

## Current corpus & stats

- ~4,316 Family Division / Family Court judgments
- ~339,725 paragraph-level vectors (384-dim, `all-MiniLM-L6-v2`)
- Case-level Citizens Advice tagging across ~109 curated concepts
- Tagging threshold and per-case tag cap are configurable
